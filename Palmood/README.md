# Palmood

Sistema web de venda de plantas e produtos para jardinagem onde o usuário escolhe o produto, a forma de pagamento, e recebe sua compra em casa.

## Funcionalidades
- Cadastro e login de clientes
- Grade com preços e fotos
- Filtro de atributos
- Montagem e envio de pedidos
- histórico de pedidos

## Tecnologias
- HTML, CSS e JavaScript

## Como rodar
**pendente**
1. Instale o XAMPP e ligue Apache e MySQL.
2. Copie a pasta `Palmood` para `C:\xampp\htdocs`.
3. No phpMyAdmin, importe `database/Palmood.sql`.
4. Acesse http://localhost/Palmood
5. Passos detalhados em `docs/instalacao.md`.
