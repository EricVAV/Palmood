# Palmood
Plants store website project

## Funcionalidades
- Cadastro e login de usuários
- Grade de produtos com preços e fotos
- Adicionar/remover forma de pagamento e endereços para entrega
- Montagem e finalização de pedidos
- Histórico de compras

  ## Tecnologias
- PHP 8.2
- MySQL 8
- HTML, CSS e JavaScript
- XAMPP (ambiente local)

  ## Como rodar
1. Instale o XAMPP e ligue Apache e MySQL.
2. Copie a pasta `Palmood` para `C:\xampp\htdocs`.
3. No phpMyAdmin, importe `palmood.sql`.
4. Acesse http://localhost/Palmood/index.php
